## LinkedIn

```
Your AI can use a real browser now.

web-mcp is a small, free tool that gives your AI assistant (Claude Code, Cursor, OpenCode, Windsurf, Zed, Codex, Cline and others) its own real Chromium browser. You ask in plain English; it does the clicking and typing while you watch.

What it's good at:
• Looking things up and reading pages for you
• Filling in forms, logging in and checking out
• Pulling information off a page: prices, tables, lists
• The boring, repetitive checks: status pages, dashboards, timesheets
• Testing your site the way a real customer would

You always see what it's doing: a live status pill on the page and a side panel with every step it takes. And it all runs on your own computer. No cloud, no telemetry; nothing is sent anywhere.

Everything in the video is a real run: Claude Code with web-mcp, given a plain request, doing the task itself. The demo stores shown (saucedemo.com, books.toscrape.com) are public test sites.

Install in one line:
npm install -g @amitnarw/web-mcp
then run web-mcp to connect your AI.
```
